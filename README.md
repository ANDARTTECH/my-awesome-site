# Сайт о мобильной разработке

Этот репозиторий содержит простую одностраничную страницу, посвящённую мобильной разработке. Чтобы открыть сайт, загрузите файл `index.html` в браузере.

В проекте находятся следующие файлы:

- `index.html` — разметка страницы с краткой информацией и ссылками на инструменты.
- `style.css` — базовые стили и поддержка светлой/тёмной темы.
- `main.js` — логика переключения темы.

Нажмите кнопку "Сменить тему" в верхней части страницы, чтобы переключаться между светлой и тёмной темой.
